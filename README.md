# Web-log

Web-log is a modern, full-stack web application built using Next.js, Prisma, and Firebase. It integrates user authentication, dynamic content management, and a sleek UI powered by Radix UI, TailwindCSS, and React.

## Features

- **Authentication**: User login and registration using NextAuth and Firebase.
- **Dynamic UI Components**: Rich UI with interactive dialogs, dropdowns, and toasts using Radix UI.
- **Responsive Design**: Styled with TailwindCSS to ensure a fully responsive experience.
- **Prisma ORM**: Database management with Prisma and seamless integration with Firebase.
- **State Management**: Global state management using Redux Toolkit.
- **Content Editing**: Rich text editor integrated with React-Quill for content creation.

## Tech Stack

- **Frontend**: 
  - React 18
  - Next.js 14
  - Radix UI Components
  - TailwindCSS (for styling)
  - React-Quill (for content editing)
  - Lucide React (for icons)

- **Backend**:
  - Prisma ORM
  - Firebase (authentication and backend storage)

- **State Management**:
  - Redux Toolkit
  - SWR (for data fetching)
